## 8. 今日技术关键词  

### Claude Code 无代码 Agent  
- 一句话解释：Anthropic 的 Agent 编程工具，让用户通过自然语言快速构建应用。  
- 为什么重要：降低了开发门槛，是 Agent 技术民主化示例。  
- 我应该怎么入门：阅读 Claude Code 文档，尝试 prompt 控制流程。  
- 推荐搜索关键词：Claude Code 无代码 Agent、Anthropic Claude Code 教程。

### MCP（Model Context Protocol）  
- 一句话解释：AI 工具调用标准协议，用于统一不同模型或工具的调用接口。  
- 为什么重要：降低集成复杂度，提升多模型系统协作可能性。  
- 我应该怎么入门：查阅 MCP 协议规范、写简单接口实现。  
- 推荐搜索关键词：Model Context Protocol MCP、MCP AI 工具调用。

### Gemini 3.5 Flash / Gemini Spark  
- 一句话解释：Google 在 I/O 发布的新一代 Gemini 多模态模型。  
- 为什么重要：代表当前多模态技术发展趋势，可能带来新功能与接口。  
- 我应该怎么入门：关注 I/O 报告中的技术细节、申请 API 测试。
