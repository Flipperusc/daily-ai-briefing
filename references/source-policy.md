# AI 学习简报来源策略

## 我的身份和目标

我是计算机专业的大二学生，对 AI、编程、软件工程、开源项目和新技术有强烈好奇心。

日报的目标不是简单罗列新闻，而是帮助我：

1. 快速了解 AI 领域最新进展。
2. 判断哪些技术方向值得持续关注。
3. 把新闻和计算机专业知识联系起来。
4. 找到可以学习、复现、实践的小项目。
5. 为未来实习、开源贡献和个人项目积累方向感。

---

## 不优先关注的内容

尽量减少以下内容：

1. 没有技术细节的融资新闻。
2. 纯营销稿。
3. 没有来源的社交媒体爆料。
4. 只是在标题里蹭 AI 热点的传统行业新闻。
5. 重复报道。
6. 只表达观点、没有事实增量的评论文章。
7. 和学习、编程、技术趋势无关的泛泛新闻。

## 新闻筛选标准

每天最多选择 10 条重点内容。

优先级评分可以参考：

### A 级：必须写

满足以下任意条件：
- 重要模型发布
- 重要 AI 产品或 API 更新
- 有重大影响的开源项目
- 有代码或 demo 的重要论文
- 影响开发者工作流的新工具
- 重大监管政策
- 可能改变 AI 应用开发方式的新技术

### B 级：可以写

满足以下任意条件：
- 中等重要的产品更新
- 有学习价值的开源项目
- 有代表性的研究进展
- 对行业趋势有启发的商业动态

### C 级：通常不写

满足以下情况：
- 没有实质内容的新闻
- 只有融资金额
- 没有技术细节
- 没有可靠来源
- 和我的学习目标关系不大

## 输出风格要求

请使用中文输出。

风格应该是：
- 清晰
- 准确
- 不夸张
- 不标题党
- 偏技术
- 适合计算机专业学生阅读
- 能指出我该学什么、做什么

不要使用过度营销化表达，例如：
- 颠覆世界
- 革命性突破
- 史诗级更新
- 彻底改变一切

除非来源中确实有充分证据支持。

---

## 真实性要求

硬性要求：

1. 不得编造新闻。
2. 不得生成虚构示例。
3. 不得使用占位符来源。
4. 每条重点新闻必须有真实来源。
5. 不确定的信息必须标注“不确定”。
6. 如果当天重大进展不足 5 条，可以少写，不能凑数。
7. 如果无法找到可靠来源，应明确说明，而不是编造。

错误示例：

- 来源：[OpenAI 官方博客]
- 来源：[GitHub Release]
- 来源：[官方新闻稿]

正确做法：

- 给出具体网页标题、机构名称和链接。
- 明确说明来源是官方公告、论文、GitHub 项目还是媒体报道。

## 学习导向要求

每份日报都要帮助我回答：

1. 今天有什么新东西？
2. 它背后的技术是什么？
3. 和我学过或将要学的计算机课程有什么关系？
4. 我可以怎么入门？
5. 有没有适合我做的小项目？
6. 这个方向是否值得长期关注？

---

## 项目建议要求

如果某条新闻适合做项目，请给出具体建议。

项目建议应该适合大二学生，难度不要过高。

格式：

- 项目名称：
- 可以实现的最小版本：
- 需要的技术：
- 预计耗时：
- 可以学到什么：

项目方向可以包括：
- 简单 RAG 应用
- AI 笔记助手
- GitHub issue 总结器
- 论文摘要工具
- 个人知识库
- 课程资料问答机器人
- AI 编程练习助手
- 简单 Agent 自动化脚本
- 本地模型部署 demo
- 多模态小工具

---

## 长度要求

日报不要太长。

建议：
- 技术关键词解释要简洁。
- 动手任务要具体。
- 避免无意义铺陈。
